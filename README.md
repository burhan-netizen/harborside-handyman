# Harborside Handyman Co.: concept website

A concept website by [Mago Labs](https://magolabs.in) for a fictional handyman and custom woodworker in Wilmington, North Carolina. Harborside Handyman Co. is not a real business: the name, logo, owner, phone number and address are invented, and the photos are stock images from Unsplash.

Single page, plain HTML, CSS and vanilla JS, no build step.

- `index.html`: the page, styles and behaviour
- `media/`: optimised photos
- `js/motion.js`: ripple and scroll helpers
- `js/fx3d.min.js`: WebGL 3D house that assembles itself in the hero (three.js, loaded after first paint)
